About EcoSim & Technical Methodology

Comprehensive academic report content, architecture, UML diagrams, and formula specifications.

3.1 Proposed Methodology

EcoSim implements an iterative, feedback-driven smart city modeling framework. Urban designers adjust fundamental zoning parameters (transit density, built mass, green canopy, and distributed solar generation). The deterministic mathematical model computes immediate environmental impacts, which are visualized through 60-FPS canvas rendering and stored in MongoDB Atlas for persistent longitudinal analysis.

3.2 Three-Tier System Architecture
Presentation Tier Client Browser: HTML5, CSS3, Bootstrap 5, Chart.js, HTML5 Canvas 2D Engine.
Application Tier Node.js / Express Server: RESTful API routing, input sanitation, validation middleware, and deterministic simulation engine.
Data Tier MongoDB Atlas: Managed cloud NoSQL database, Mongoose ODM schemas, structured BSON persistence.

Simulation Formulas
  • Traffic: $Congestion\% = \min(100, \frac{V_{effective}}{V_{effective} + C_{road}} \times 100)$
  • Solar: $P_{daily} = N_{panels} \times 1.75\text{ kWh}$; Coverage against $N_{bld} \times 35\text{ kWh}$.
  • Pollution: $Net = \max(0, (0.085 V + 0.05 B) - (0.038 T + 0.035 S))$.
  • Greenery: $Canopy\% = \frac{\text{Tree Area} + \text{Parks}}{\text{Total Urban Area}} \times 100$.

MongoDB Atlas Connection Guide
Security Notice: Database credentials should never be entered into chat or frontend forms. Enter them directly into your local .env file.
Step 1: Get Connection String from MongoDB Atlas
  1. Log in to MongoDB Atlas.
  2. In the left sidebar, click Database or Clusters.
  3. Click the Connect button next to your cluster.
  4. Choose Drivers (Select Node.js).
  5. Copy the provided connection string.
Step 2: Paste in EcoSim/.env

Open the file: EcoSim/.env in your editor. Replace line 1 with your connection string:

MONGODB_URI=mongodb+srv://<username>:<password>@<cluster>.mongodb.net/ecosim
Important Tips:
  • Replace <username> and <password> with your actual Atlas database user (remove the angle brackets < >).
  • Make sure the database name is ecosim.
  • If your password contains special characters like @, :, or /, URL-encode them (e.g. @ becomes %40).
  • In Atlas > Network Access, ensure your IP address is whitelisted (or 0.0.0.0/0 for access from anywhere).
Step 3: Save and Verify

Press Ctrl+S to save .env. Then click the button below to test the connection immediately!
